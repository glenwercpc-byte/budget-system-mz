# CCPC 예산 앱 (Chicago Covenant Church Budget App)

재정부 지침에 따라 **매년 반복 사용할 수 있는** 예산 편성 도구입니다.
구글 시트(실제 작업 공간) + Google Apps Script(자동화 코드)로 구성됩니다.

## 무엇을 해주나요

- 기준연도 지출 내역(회계 프로그램의 Profit & Loss Detail)을 붙여넣으면
  계정·항목별로 자동 집계합니다.
- 재정부 계산 규칙을 그대로 적용해 다음 해 예산안 초안을 만듭니다.
  - **고정 지출**: 월 평균 × 12
  - **변동 지출**: 실적 ÷ 실적 개월 수 × 12 (예: 9개월 실적 × 1.333)
  - **연 1회/일회성**: 비례 환산 없이 실제 예정 금액만 반영
  - **Refunds & Credits**: 예산 산출에서 제외
  - 4분기 계절 요인 등은 항목별 **조정률**로 반영
- 기준연도 예산 vs 실적 비교표, 인사관리 예산 Worksheet 구조를 포함합니다.
- 해가 바뀌면 메뉴 한 번으로 새 연도 워크북을 만들어 같은 방식으로 반복합니다.

## 구성

| 파일/탭 | 설명 |
| --- | --- |
| `apps-script/Code.gs` | 예산 앱 메뉴, 자동 계산, 새 연도 워크북 생성 |
| `apps-script/Setup.gs` | 빈 시트에 전체 탭 구조를 만드는 초기 설정 함수 |
| `apps-script/appsscript.json` | Apps Script 프로젝트 설정 (시간대 America/Chicago) |
| `template/CCPC_예산앱_템플릿.xlsx` | 코드 없이 바로 열어 쓸 수 있는 엑셀/구글시트 템플릿 (수식 포함) |

구글 시트 탭: `사용법` · `설정` · `계정목록` · `분류기준` · `거래내역` · `예산안` · `비교표` · `인사관리`

## 시작하는 법

### 방법 A — 만들어진 구글 시트 사용 (권장)
1. 공유받은 "CCPC 예산 앱" 구글 시트를 엽니다.
2. 상단 메뉴 **[📊 예산 앱]** 에서 작업을 실행합니다.
   - 처음 한 번은 구글 권한 승인 창이 뜹니다 (본인 계정으로 승인).

### 방법 B — 새 시트에 직접 설치
1. 새 구글 시트를 만들고 **확장 프로그램 → Apps Script**를 엽니다.
2. `apps-script/`의 `Code.gs`, `Setup.gs` 내용을 붙여넣고 저장합니다.
3. `setupWorkbook()`을 한 번 실행하면 모든 탭이 생성됩니다.

### 방법 C — 템플릿 파일 사용
`template/CCPC_예산앱_템플릿.xlsx`를 구글 드라이브에 올리고 구글 시트로 열면
수식이 그대로 동작합니다.

## 매년 사용 순서

1. **[📊 예산 앱] → 새 연도 워크북 만들기**로 올해용 워크북을 복사합니다.
2. 회계 프로그램에서 기준연도(1~9월) 지출 상세 보고서를 받아
   `거래내역` 탭에 붙여넣습니다. (열 순서: 계정번호, 계정명, 카테고리, 날짜, 거래유형, Num, 거래처, 내역, 금액)
3. **[📊 예산 앱] → 분류기준 기본값 채우기** 후, 카테고리별 지출 성격
   (고정/변동/일회성/제외)을 확인·수정합니다.
4. **[📊 예산 앱] → 거래내역 → 예산안 자동 생성**을 실행합니다.
5. `예산안` 탭에서 조정률과 일회성 예정액을 다듬고, `비교표`로 검토한 뒤 제출합니다.
6. 인사 항목은 `인사관리` 탭에서 별도로 검토합니다.

## 데이터 보안

  넣지 마세요. 데이터는 교회 구글 계정의 시트 안에만 둡니다.
